# ERP Inventory API

A robust RESTful API built to manage inventory, track stock levels, and handle pricing efficiently.

## Features
- **Inventory Management**: Comprehensive endpoints to manage products, pricing, and stock levels.
- **CRUD Operations**: Full Create, Read, Update, and Delete operations with request validation.
- **Low-Stock Alerts**: Automated functionality to flag inventory items that fall below defined thresholds.
- **Relational Database**: Well-designed database schemas ensuring robust data consistency and integrity.

## Tech Stack
- **Framework**: FastAPI
- **ORM**: SQLAlchemy
- **Database**: PostgreSQL

## Deployment
This application is deployed on [Railway](https://railway.app/) with seamless PostgreSQL integration.
